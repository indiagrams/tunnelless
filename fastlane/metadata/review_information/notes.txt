IMPORTANT -- NO SEPARATE TAILSCALE APP REQUIRED

Tunnelless has Tailscale built in. Do NOT install the Tailscale app. The Tailscale
sign-in screen on first launch is account authentication only -- it connects this
app's own embedded node to that account's network.

ABOUT THIS APP

Tunnelless joins a Tailscale network from inside the app itself, without
installing a VPN profile. Only this app's own connections use the network; the
rest of the device is unaffected and any VPN the user already runs keeps working.
It is analogous to an SSH or FTP client: it connects to a network the user already
has. Demo credentials are in the App Review Information section above.

HOW TO REVIEW

1. Launch the app. It begins connecting immediately.
2. A Tailscale sign-in page opens in an in-app browser. Sign in with the demo
   credentials provided above.
3. The sheet closes by itself once connected. Tailscale's flow ends on its own
   website and never redirects back, so the app watches its own node instead --
   expected, no action needed.
4. The main screen shows the device's private address (100.x.y.z) and the local
   SOCKS5 proxy address the app uses to reach other machines.
5. "Browse tailnet" lists the demo account's devices. Offline devices are expected
   -- they are simply not powered on. At least one should be online.
6. "Sign out & reset" removes the node and deletes its stored credentials.

VPN -- the app has no VPN features, and collects no user information

The app does not use NetworkExtension. There is no NEPacketTunnelProvider, no VPN
configuration, no VPN profile, and it does not request the
com.apple.developer.networking.networkextension entitlement. It never installs a
system VPN, never triggers an "Allow VPN configuration" prompt, and never routes
or intercepts traffic belonging to any other app.

Instead it links Tailscale's tsnet as a library and runs a userspace network node
inside its own process, exposing a local SOCKS5 proxy that only this app uses. The
scope of the connection is this app's own traffic and nothing else.

- What user information is collected: none. No analytics, no tracking, no
  telemetry, no crash reporting. This matches the app's privacy manifest and its
  "Data Not Collected" App Privacy declaration.
- For what purposes: not applicable, as nothing is collected.
- Shared with third parties: no. We operate no servers and receive no user data.
  The user signs in to their own existing Tailscale account; that authentication
  happens directly with Tailscale in an ASWebAuthenticationSession against
  Tailscale's own site, and the app never sees those credentials. Network state is
  stored only on the device and is deleted when the user signs out. Tailscale is
  the user's own pre-existing network provider, not a party we send data to.

SANDBOX (macOS only) -- com.apple.security.network.server is REQUIRED

tsnet binds a listening socket on loopback: the SOCKS5 proxy this same app
connects through. App Sandbox requires network.server for any listening socket,
including a loopback-only one. Measured on signed builds of one binary, varying
only entitlements:

  sandbox alone    -> tailscale_start() res=-1
  + network.client -> res=-1
  + network.server -> res=0

Without it the node never starts and the app cannot connect to anything. The app
accepts no inbound connections from outside the device; the listener is on
loopback. The userspace WireGuard transport must also receive UDP from the user's
own peers and from DERP relays, which is inherent to WireGuard.

Tunnelless has no user accounts, servers, or sign-up of its own. Tailscale is a
registered trademark of Tailscale Inc.; Tunnelless is not affiliated with or
endorsed by Tailscale Inc.

Local network permission is requested on first connect, to reach devices on the
same physical network directly rather than relaying. Declining it does not break
the app -- connections simply take the relayed path.
